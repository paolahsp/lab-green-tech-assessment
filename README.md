# Defend Your Stack's Carbon Story

This repository contains the complete submission for the Ironhack **Green Software & Sustainable AI** lab.

## Chosen path

**Path B - Green retrofit audit**

The audited artifact is [Intellectus / Social Impact Consulting Intelligence](https://github.com/paolahsp/Social-Impact-Consulting-Intelligence), an n8n-based, consultant-facing diagnostic workflow for social-impact organizations.

## Core assessment

**Functional unit (R):** one completed, evidence-grounded diagnostic report for one social-impact organization, ready for consultant review.

The audit recommends a measured retrofit pilot focused on:

1. caching and deduplicating public evidence;
2. conditional routing and fewer unnecessary model calls;
3. right-sized models with quality evaluation;
4. smaller payloads and explicit retention;
5. on-demand execution and carbon-aware infrastructure choices where feasible.
